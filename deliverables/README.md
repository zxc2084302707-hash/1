# PickVela video delivery

`pickvela-scrunchies-vs-clips-30s.mp4` is a 30-second, 1080x1920, silent English text video for the PickVela style poll. It uses the Pexels reference images documented in `PHOTO-SOURCES.md`. It does not show real vote totals or make product availability claims. This branch is only for delivery; it is not deployed to the live Render website.

Source images: Pexels 6044144 and 20166053. This version has no voiceover because the owner selected the silent version.
